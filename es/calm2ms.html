Por qué lo necesitan los equipos

Los documentos de tu proyecto viven en dos mundos.

Cloud ALM es donde se sigue el proyecto. SharePoint es donde la gente de verdad escribe, revisa y firma los documentos. Mantener los dos al día a mano no dura.

Un segundo almacén de documentos

Sin Calm2MS, los archivos están en un almacén de documentos aparte, el servicio de documentos de SAP en BTP: un servicio más que pagar y mantener.

Fuera de tu Microsoft 365

Los archivos guardados en otro sitio se quedan sin tus permisos de SharePoint, directivas de retención, etiquetas de confidencialidad y búsqueda.

Copias que se desincronizan

El equipo edita en Word o Excel, alguien lo sube a Cloud ALM y pronto nadie sabe qué copia es la vigente.

Difícil de encontrar

Sin carpetas ni columnas que sigan al proyecto, encontrar el documento de un requisito o de un test lleva demasiado tiempo.

Cómo funciona

Sube en cualquiera de las dos herramientas. Calm2MS hace el resto.

Cloud ALM se conecta a Calm2MS en lugar de a un servicio de documentos aparte. Calm2MS mantiene un solo archivo en tu biblioteca de SharePoint y lo vincula a Cloud ALM.

Un solo archivo

El archivo existe una sola vez, en tu biblioteca de SharePoint. Cloud ALM lo lee desde ahí; no hay una segunda copia.

Historial de versiones

Ábrelo en Word o Excel y guarda: SharePoint conserva cada versión y Cloud ALM abre la última.

En los dos sentidos

Suelta un archivo en una carpeta del proyecto en SharePoint y se convierte en un documento de Cloud ALM, con su enlace de vuelta.

Organizado como el proyecto

Una carpeta por proyecto y, dentro, por proceso, requisito, tarea o test, con columnas por las que se puede filtrar.

Acceso

Solo el sitio que tú elijas.

Calm2MS usa el permiso Sites.Selected de Microsoft: solo puede acceder al sitio de SharePoint que le des, nunca al resto de tu tenant. Tu administrador de Microsoft 365 aprueba ese acceso una sola vez.

En Cloud ALM usa una clave de API con los scopes que necesita, y su consola te avisa de cualquier scope que no necesite.

Qué necesitas
  • Un tenant de SAP Cloud ALM y una clave de API para él
  • Un sitio de SharePoint Online para los documentos, en tu Microsoft 365
  • Un administrador de Microsoft 365 que apruebe el acceso a ese único sitio
Tus archivos siguen siendo tuyos

Todo está en tu SharePoint, con tu retención y tus permisos. Microsoft 365 Copilot también puede buscar en los archivos, con tus propias licencias.

Precio

Un precio por tenant. Sin coste por usuario.

Calm2MS tiene un precio por tenant de Cloud ALM, con todos sus proyectos. Todas las personas que trabajan con los documentos están incluidas. Presupuestamos cada tenant en una propuesta; la migración se presupuesta aparte.

Calm2MS Migration

¿Vienes de Solution Manager? Trae tus documentos.

Calm2MS Migration lleva tu documentación de Solution Manager a Cloud ALM, con los archivos en tu biblioteca de SharePoint.

Con el SDT de SAP

Selective Data Transfer mueve la estructura y los documentos. Calm2MS pone los archivos en SharePoint y hace que Cloud ALM apunte a ellos.

Sin SDT

A partir de dos listas estándar de Solution Manager, Calm2MS Migration crea la jerarquía, las bibliotecas, los procesos con sus diagramas y los documentos mediante las APIs de Cloud ALM. Una simulación lo muestra todo antes de escribir nada.
