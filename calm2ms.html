Access

Only the site you choose.

Calm2MS uses Microsoft's Sites.Selected permission: it can reach only the SharePoint site you give it, never the rest of your tenant. Your Microsoft 365 admin approves that access once.

In Cloud ALM it uses an API key with the scopes it needs, and its console warns you about any scope it does not need.

What you need
  • SAP Cloud ALM tenant and an API key for it
  • SharePoint Online site for the documents, in your Microsoft 365
  • Microsoft 365 admin to approve access to that one site
Your files stay yours

Everything sits in your SharePoint, under your retention and permissions. Microsoft 365 Copilot can search the files too, with your own licenses.

Pricing

One price per tenant. No fees per user.

Calm2MS is priced per Cloud ALM tenant, with all its projects. Everyone who works with the documents is included. We quote each tenant in a proposal; migration is quoted separately.

Calm2MS Migration

Moving from Solution Manager? Bring your documents.

Calm2MS Migration moves your Solution Manager documentation to Cloud ALM, with the files in your SharePoint library.

With SAP's SDT

Selective Data Transfer moves the structure and the documents. Calm2MS puts the files in SharePoint and points Cloud ALM to them.

Without SDT

From two standard Solution Manager lists, Calm2MS Migration builds the hierarchy, libraries, processes with their diagrams and documents through the Cloud ALM APIs. A simulation shows everything before anything is written.
